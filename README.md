# 绍宋决 · Shao Song Jue

基于穿越小说《绍宋》（榴弹怕水 著）的网页卡牌对战游戏，规则类似万智牌（MTG），单 HTML 文件自包含。

## 玩法

- **胜利条件**：将对手威望（生命）打到 0，或对手牌库抽空。初始威望 20。
- **战牌**：60 张一副（22-24 张地），同名最多 4 张。
- **模式**：AI 对战、自定义牌组、同屏双人。

## 回合流程（手动点"下一阶段"推进）

重置 → 维持 → 抽牌 → **战前主阶段**（出牌下地）→ 战斗开始 → **宣告攻击**（点将选目标）→ 宣告阻挡 → 结算伤害 → 战斗结束 → **战后主阶段** → 结束回合 → 清除

## 阵营颜色轮

| 阵营 | 色 | 特性 | 关键词 |
|---|---|---|---|
| 宋 | 红 | 将攻击 +1（士气） | 死守、北伐、先发 |
| 金 | 金黄 | 破甲（超额伤害打玩家） | 铁浮屠、陷阵 |
| 夏 | 绿 | 将敏捷（召唤当回合可攻） | 游击、牧场 |
| 理 | 紫 | 将攻击后挂 -1/-1（蛊毒） | 巫蛊、穿喉、抚绥 |
| 中立 | 蓝 | 灵活应变 | 庙算、纵横 |
| 后宫 | 粉 | 居中牵制，辅助所有阵营 | 返照、命令、北狩 |
| 伪齐 | 灰 | 见风使舵 | — |

**相克环**（攻击被克方 +1 攻）：宋 → 金 → 夏 → 理 → 宋
**相生环**（同场盟友 +0/+1）：宋↔中立、金↔夏、夏↔理、中立↔后宫
**后宫居中**：辐射所有阵营，通过返照/弃牌影响各方

## 卡牌类型

- **将领**：攻防单位
- **州府/地**：产粮（单色地、双色地、异国无色地）
- **名品（sorcery）**：只能主阶段用
- **计策（instant）**：任意阶段可用
- **衍生物**：骑兵 2/2 敏捷、刀斧手 2/3、弓箭手 1/2 穿喉、亲兵 0/3 铁壁

## 关键词

穿喉、敏捷、死守/铁壁、列阵、陷阵、强弩、抚绥、先发、破阵、庙算、营田、血战、反问、纵横、勤王、坚壁、殉国

## 本地运行

直接用浏览器打开 `绍宋决.html` 即可，无需服务器、无需安装依赖。

## 技术栈

- 单文件 HTML（内联 CSS + 原生 JS）
- 无框架、无构建工具
- localStorage 保存录像回放与自定义牌组
